# Restaurant Revenue Prediction

## Project Overview

This project focuses on predicting restaurant revenue using machine learning techniques in Python. The dataset was cleaned and preprocessed, followed by exploratory data analysis and feature engineering to identify factors influencing restaurant revenue.

Multiple regression algorithms were implemented and compared, including **Linear Regression, Decision Tree, Random Forest, and Support Vector Regression (SVR)**. The models were evaluated to identify the most suitable approach for predicting restaurant revenue.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Key Steps

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Label Encoding
* Feature Scaling
* Feature Engineering
* Model Training and Evaluation
* Comparison of Multiple Machine Learning Models
